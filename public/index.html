📧 Gmail Configuration

🔐 How to get Gmail App Password

⚠
App Password is a 16-character code Gmail generates. You use it instead of your real password so apps can send email securely.
1
Enable 2-Factor Authentication Go to myaccount.google.com → Security → 2-Step Verification → Turn ON (required first)
2
Open App Passwords Go to myaccount.google.com/apppasswords (direct link)
3
Create new app password App name: type IITM Mailer → click Create
4
Copy the 16-character code Looks like: abcd efgh ijkl mnop — paste it above (spaces are OK)
✓
After this, emails you send will appear in your Gmail Sent box normally.

🚀 Deploy Backend (for real sending)

This app needs a Node.js backend to actually send emails (browsers can't do SMTP).

1
Upload to GitHubUpload the server.js + package.json + this index.html (in a public/ folder)
2
Go to render.com → New Web ServiceConnect your GitHub repo. It's free.
3
Set Environment Variables on Render GMAIL_USER, GMAIL_PASS, GEMINI_KEY
4
Paste the Render URL in the Backend URL field in the sidebar
